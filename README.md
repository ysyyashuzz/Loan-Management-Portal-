Loan Management Portal 

This is a simulated version of a full-stack Java loan application portal built during internship. The original project involved sensitive data and client-specific requirements. This public version has been recreated using mock data and safe components.

Tech Stack
- Java + Spring Boot (backend)
- HTML/CSS (frontend)
- MySQL (database)
- REST APIs (Spring Controller)

Features
- Apply for a loan via form
- Credit-score-based loan decision
- View all submitted applications (mock API)


Project Structure
- `backend/` – Spring Boot backend code
- `frontend/` – Simple frontend UI
- `sql/` – SQL schema and test data

Live Demo
You can deploy this using Render or localhost.
